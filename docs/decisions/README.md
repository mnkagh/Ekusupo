# Architecture Decision Records

ADRs live here for decisions that materially affect architecture, tech
stack, data model, provider abstraction, auth, deployment, security, AI
policy, or API versioning. See
[CLAUDE.md §18.3](../../CLAUDE.md#183-architecture-decision-records).

Name new ADRs `NNNN-short-title.md` (e.g. `0001-monorepo-layout.md`) and use
this template:

```text
# ADR-0001: Title

Status: Proposed | Accepted | Superseded

## Context
## Decision
## Consequences
## Alternatives Considered
```
